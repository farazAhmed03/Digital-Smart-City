# Digital Smart City - ECS Fargate + ALB Ephemeral DevOps Package

## What this package adds

This package is designed for a short production-like deployment proof:

```text
Deploy -> Smoke test -> Manual/client check -> Destroy
```

It keeps the original domain untouched:

```text
https://www.kohat.online/
```

The temporary test URL is the AWS ALB DNS name generated by Terraform.

## Architecture

```text
ALB HTTP URL
  -> ECS Fargate service
     -> one task
        -> frontend nginx container :8080
        -> backend Node.js container :5000
  -> MongoDB Atlas testing DB
```

The frontend nginx container proxies backend/API paths to the backend sidecar container using localhost networking inside the same ECS task.

## Cost-control defaults

```text
No NAT Gateway
No Route53
No ACM certificate
No permanent domain
No EKS cluster
ECS desired_count = 1
ECS max_capacity = 2
CloudWatch log retention = 3 days
```
